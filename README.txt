Word Recall v6.0 Beta 4.4

本版严格以已核对的 v6.0 Beta 4.3 verified 作为唯一开发基线。

本版在保留 Beta 4.3 发音稳定性升级、Beta 4.2 Review Session 与四任务逻辑的基础上，优化“今日”页任务进度与文案：
1. 顶部四个复习任务卡片增加今日任务进度：今日到期、历史积压、长期巩固、薄弱词恢复均显示“今日 x/y”，完成后显示“已完成”；无任务显示“今日无任务”。
2. 今日计划中的正常复习节点不再硬编码，自动读取设置中 <=30 天的间隔节点。
3. 长期巩固节点不再硬编码 60/90/180，自动读取设置中 >30 天的间隔节点。
4. 修正文案：历史积压与薄弱词不再把“当前到期待处理数量”误写成“今日释放”；改为“当前待处理 + 今日完成进度”。
5. 每日释放上限按当天已完成数量扣减，完成当日上限后不会再次释放下一批，保证“每日上限”语义一致。
6. 今日进度以完成中文→英文第二轮的唯一单词数计数；Again 补救仍按原逻辑继续，不重写评分/补救机制。
7. “今日正常复习阶段”模块保持原样，不改现有批次体验。
8. 使用说明中的正常复习节点顺序也随设置动态更新。
9. 保留原 Review Session 本地存储 key、四档评分、两轮复习、Again、错词本、导入导出、日历和 Beta 4.3 发音模块。

部署前建议先导出 JSON 备份。
