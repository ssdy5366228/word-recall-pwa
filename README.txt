Word Recall v5.8.2

本次升级：
1. iPhone 复习发音授权
   - 进入普通复习后，先显示“开始复习并启用发音”。
   - 只需点击一次，即可播放当前单词，并允许后续英文→中文自动发音。
   - 中文→英文仍不在出题前播放。

2. 正常复习拆分
   - 第一阶段：只复习今天真正到期的单词（nextReviewDate 等于今天）。
   - 第二阶段：完成今日到期后，再选择是否恢复历史积压。
   - 历史积压不再混入“今日正常复习”数字。

3. 新增可设置的正常积压释放数量
   - 设置项：每日正常复习积压释放数量。
   - 0 表示当天不释放；999 近似全部释放。
   - 默认 10 个。

数据兼容：
- 保留 v5.7.x 词库、复习日志、错词和设置。
- 不修改正常复习间隔，不清空数据。
- 部署前仍建议先导出 JSON 备份。

部署：
将本文件夹内的 index.html、app.js、styles.css、sw.js、manifest.webmanifest 和图标文件全部覆盖到 GitHub Pages 仓库根目录。

- 历史积压在今日到期完成后再进入，并受“每日正常复习积压释放数量”限制。
