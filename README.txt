Word Recall v5.7.1（发音升级版）

本版本基于已部署的 v5.7 正式版升级，保留原有词库、错词、日志、复习计划和数据安全机制。

一、本次发音升级
- 发音改为“词典音频优先，iPhone 系统发音兜底”。
- 第一次播放某个单词时自动联网查询免费词典音频；查询成功后立即播放。
- 音频可缓存到本机，之后再次遇到同一单词时优先直接播放缓存。
- 不预先下载全部 969 个词，只对实际复习、点击或新录入的单词随需获取。
- 可在设置中选择美式英语或英式英语；优先匹配所选口音，没有时自动使用另一种可用口音。
- 播放新词前会停止上一段发音，避免两个单词重叠。
- 同一张卡片因界面重复渲染时不会重复自动播放。

二、自动发音
- 英文→中文复习切换到新单词时可自动播放，默认开启。
- 普通复习与薄弱词复习均支持自动播放。
- 中文→英文出题前不播放，也不显示喇叭，避免泄题。
- 中文→英文显示答案后，可手动点击喇叭听发音。
- 若 iPhone 阻止首次自动播放，先手动点击一次喇叭即可继续使用。

三、新词录入
- 新词保存成功后，可自动查询并缓存词典发音，默认开启。
- 发音查询失败不影响单词保存，也不会影响词库和复习记录。
- 编辑单词英文拼写后，会为新拼写重新尝试获取发音。

四、缓存与数据安全
- 音频独立存放在浏览器 Cache Storage 中，不写入词库 JSON，也不参与每次评分的数据保存。
- 音频缓存即使被系统清理，也只需下次重新联网获取，不会造成词库、日志或错词数据丢失。
- Service Worker 更新时保留发音缓存，同时更新应用静态资源缓存到 5.7.1。
- v5.7 的本地数据可直接延续使用，不需要重新导入 969 词 JSON。

五、发音来源
- 在线查询使用 Free Dictionary API（dictionaryapi.dev）。
- 若词典没有音频、网络不可用或音频无法播放，则自动使用浏览器系统英文语音作为备用。

部署：将本文件夹内全部文件覆盖上传到 GitHub Pages 仓库根目录。部署后在 iPhone Safari 中刷新；若仍显示旧版本，可关闭页面后重新打开，确认首页底部显示 Version: v5.7.1。
